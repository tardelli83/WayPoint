# Waypoint

Waypoint is a Django-based web application designed to manage and explore parks and trails.

## Features
- Browse a catalog of trails with details on distance, elevation, and difficulty.
- Filter and view open trails.
- Built-in Django administration panel for managing parks and trail data.
